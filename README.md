# Сайт веб-аналитика Натальи Авдеевой

Статическая версия сайта avd-web.tilda.ws для хостинга на GitHub Pages.
В отличие от бесплатного тарифа Tilda, здесь подключена Яндекс Метрика (счётчик 114019436) с целями на клики.

Основной сайт: [avd-analytics.ru](https://avd-analytics.ru/). Этот репозиторий `avdeeva_analytics` публикует сайт; `avd-web` хранится отдельно как резервная копия.

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Главная страница |
| `privacy.html` | Политика конфиденциальности |
| `css/style.css` | Оформление |
| `js/main.js` | Метрика, цели, cookie-баннер, мобильное меню |
| `images/` | Логотип (`logo.svg`, `logo.png`), иконки вкладки (`favicon-32.png`, `apple-touch-icon.png`), аватарка для соцсетей (`avatar-512.png`), фото (`photo.jpg`) |
| `robots.txt` | Настройки для поисковиков |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Перед публикацией

1. **Политика конфиденциальности.** В `privacy.html` впишите отчество вместо `[Отчество]` и покажите текст юристу.

## Публикация

GitHub Pages публикует ветку `main` этого репозитория из корневой папки. Пользовательский домен `avd-analytics.ru` задан в файле `CNAME`; HTTPS включён. DNS домена управляется в панели Timeweb.

## Яндекс Метрика

- Счётчик запускается **сразу при открытии страницы**, cookie-баннер только уведомляет. Если посетитель нажал «Отказаться», сбор останавливается, а при следующих визитах счётчик не подключается.
- Включены: карта кликов, Вебвизор, отслеживание ссылок, точный показатель отказов.
- В настройках счётчика в Метрике укажите адрес нового сайта.

### Цели — создать в Метрике

Метрика → **Цели** → **Добавить цель** → тип **JavaScript-событие** → идентификатор:

| Идентификатор | Когда срабатывает |
|---|---|
| `click_order` | Клик по любой кнопке «Заказать» / «Узнать подробнее». В параметре `service` — какая услуга |
| `click_phone` | Клик по номеру телефона |
| `click_email` | Клик по почте |
| `click_telegram` | Клик по кнопке Telegram (в блоке контактов и «Бесплатная консультация 15 минут» на первом экране — у неё `service=hero_free_call`) |
| `click_max` | Клик по кнопке MAX |

Значения параметра `service`: `hero_audit`, `hero_free_call`, `pains_cta` (оранжевая карточка «Узнали свою ситуацию?»), `sale_check`, `ux_review`, `year_report`, `checklist` (кнопка «Получить чек-лист» — цель `click_telegram`), `consultation`, `audit`, `setup`, `support`, `calls_review` (разбор звонков и переписок), `prices_free_call` (карточка «Не знаете, что выбрать?» в ценах — цель `click_telegram`).

## SEO и ИИ-ассистенты

| Что | Где |
|---|---|
| Заголовок и описание для поиска | `<title>` и `<meta name="description">` в начале `index.html` |
| Структурированные данные (услуги, цены, контакты, сертификаты) | блок `application/ld+json` в `<head>` `index.html` |
| Частые вопросы | секция `id="faq"` и блок `FAQPage` сразу под ней — тексты дублируются, правьте в обоих местах |
| Карта сайта | `sitemap.xml` (обновите `lastmod` при крупных правках) |
| Краткая справка для ИИ-ассистентов | `llms.txt` |
| Правила для роботов | `robots.txt` |

**Если поменяли цены или контакты** — обновите их на странице, в блоке `ld+json`, в FAQ и в `llms.txt`.

## Как менять тексты

Все тексты лежат в `index.html` — откройте файл на GitHub, нажмите на карандаш (**Edit**), поправьте текст и нажмите **Commit changes**. Сайт обновится через 1–2 минуты.

Блок «Актуально сейчас» (`id="actual"`) — сезонный, после Нового года его стоит обновить.
